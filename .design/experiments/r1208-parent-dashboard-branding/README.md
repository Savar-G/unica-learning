# Parent dashboard branding

Before and after use the same invented family, workbook, progress and billing scenarios. Captures are from Aside against the local Next.js dev server, first at the baseline and then with the patch. Desktop is 1440 × 1000 and phone is 390 × 844.

The local preview rendered the app’s components with the repository’s sample dashboard data. The Scan QR code pointed to the local preview. The photo sheet opened with a sample page and no uploaded image. The preview had no live account, payment, upload or email actions.

The five main views also passed horizontal overflow checks at 375 and 768 px with a long sample name. The [manifest](manifest.json) records the computed type, marker, border and shadow measurements.
