## Falsifiers

- Pending: a default result or completed page before all required checks fails.
- Saved: any Right/Wrong/Blank result without Change this mark fails.
- Prior parent decision: a missing choice or lost reading fails.
- Expired/deleted image: a disabled judgment or storage/model request fails.
- Concurrent devices: two successful writes for one version or a silent conflict fails.
- Conflict: a stale result or a hidden warning fails.
- Recovery: a saved judgment lost after publication/profile failure fails.
- Unscored/Try first: new mastery evidence fails.
- Admin: missing actor, server time or a history page fails.
- Phone/tablet/laptop: clipped choices, inaccessible focus or a target below 44 px fails.
