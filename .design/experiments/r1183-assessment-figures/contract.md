# Assessment figures

Use the existing assessment question card, controls and colour tokens. Draw each figure between its question and answers. Give rulers, plots and number lines the card width on phones. Keep clocks and shapes compact, with enough space around their marks and labels. Readings depend on position, tick marks and labels.

Supply a text alternative with the observations a child can make from the figure. For example, describe where the clock hands point without giving the digital time. For a graph, state the plotted values without calculating the comparison. Use invented questions on the actual assessment screen for review.

The bank uses new template IDs for changed questions. A filled figure belongs to the saved question together with its prompt and marking key.
