# Preview from marks

The admin child page links to a saved preview for one skill and step in a delivered Book 1. The admin chooses a cutoff date in Vancouver time and Days 1 to 7 or all available days. For the current date, the cutoff is the time of the request. For an earlier date, it is the end of that date. The saved record keeps the exact cutoff and consumed mark versions. The page compares two saved previews for the same child, book and skill. It lists added, removed and moved plan steps and changed pages. New and changed marks are evidence, not proof that a particular mark caused a plan change.

The page calls `saveAdminWorkbookPreview` with the server-only `workbookPreviewRepository`. This reads the delivered book, its saved Book 1 starting record and the correction ledger. It saves a version 2 preview and reads it back. It does not queue, render or approve a workbook.

The saved preview applies one skill decision. The pure `previewMultipleWorkbookSkills` function in `src/lib/workbook-progress-plan.ts` accepts an array of `WorkbookPlanPreviewInput` and returns `MultiSkillPreviewResult`. It validates those inputs and plans once, holding unfinished prerequisites. It does not capture the full issued-skill set from a stored book or save a version 3 result. It is not a queue admission interface. Review timing, missed-review calculation, the full spaced schedule and later-book starting records are not implemented here. Admin previews use version 2. There is no version 3 preview migration.

For #476 and D-308, no queue-ready snapshot entry point exists yet. The current single-skill output is not a full next-book snapshot. Do not use it to queue or refresh a real multi-skill draft. The U16 synthetic test shows why: the book issues earlier-level review steps without a proved mastery prefix, and one scheduled review has no matching printed question. A source adapter must retain those distinctions and must not infer a mark or mastery. The comparison only identifies changed plan pages and evidence; it does not redraw pages or preserve edits.
